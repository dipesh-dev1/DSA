# Data Structures and Algorithms

My practice repository for Data Structures and Algorithms (DSA). It holds implementations of core data structures and classic algorithms, along with solved problems, written to build strong problem-solving skills and a clear understanding of how and why each technique works.

## What this repository covers

### Data structures

- Arrays and strings
- Linked lists (singly, doubly, circular)
- Stacks and queues
- Hash tables
- Trees (binary trees, binary search trees, heaps)
- Graphs

### Algorithms

- Searching (linear search, binary search)
- Sorting (bubble, selection, insertion, merge, quick, heap)
- Recursion and backtracking
- Dynamic programming
- Greedy algorithms
- Graph traversal and shortest paths (BFS, DFS)
- Time and space complexity analysis (Big O)

## Learning approach

1. Understand the idea behind the data structure or algorithm.
2. Implement it from scratch without relying on built-in shortcuts.
3. Test it with normal cases and edge cases.
4. Analyze its time and space complexity.
5. Practice by solving related problems.

## Getting started

Clone the repository:

```bash
git clone https://github.com/dipesh-dev1/DSA.git
cd DSA
```

Each solution is a self-contained file, so you can open any one of them and compile or run it with the usual tools for its language.
